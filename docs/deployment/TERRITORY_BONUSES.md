# 领地加成部署与验收

适用于 `1.0.0`。建筑返还使用当前数据库结构；信标效果改为依据世界中的有效来源实时计算，无需数据库迁移或手工回填。默认配置见 [配置说明](../setup/CONFIGURATION.md)。

## 建筑返还

本镇成员在本镇有效 Residence 内，以生存模式放置合格单方块，默认 25% 概率返还一个同种方块；成功仅播放拾取音效，不展示内部额度。背包满时物品掉在玩家身边。

内部按“小镇、玩家、周”计数，默认每组每周 3000 次，按 `reset-zone` 的周一 00:00 切换，默认上海时间。旧计数保留 12 周；这不影响永久公共账本。

隔离验收时把概率改为 `1.0`、上限改为 `2` 并重启：

- 同一成员在本镇合格放置恰好返还两次，另一个成员单独计数；重启不重置本周额度。
- 镇外、他镇、创造、访客、自动或多方块放置不返还。
- 容器、床/门、信标、活塞、黏液块、带元数据物品及黑名单材料不返还。
- SQLite 故障不绕过额度；恢复后重新验证。验收结束恢复部署参数并重启。

## 领地信标

有效信标的当前主效果、次效果扩散至整个小镇有效 Residence，默认每 100 tick 校验来源并续期玩家效果，允许 20~200 tick。进入者不必有本镇成员身份。镇长和副镇长在真正提交效果时也要通过编辑权限检查。

启动、领地索引更新和区块加载后，系统分批检查已加载领地区块中的方块实体以发现信标，并监听放置、激活、设置效果等事件。只读取已加载来源，不添加区块票据或保活；来源区块停止方块运算或卸载后暂停贡献，恢复运行后重新验证。信标必须具有有效等级和实际光束；Paper 26.2 的光束状态由一个只读适配器读取原生方块实体，升级 Paper 时需要回归验证。

同类效果取当前有效来源的最高等级，同等级取最长原版持续时间。切换、遮挡、拆除、降级、离开领地、归档、关闭开关或停用插件后，不再续期旧效果；已有效果自然消退，不主动移除药水效果。每次持续时间沿用原版 220/260/300/340 tick（11/13/15/17 秒），残留从最后一次续期计算，来源检测还受刷新周期和原生信标更新影响。

旧 `town_beacon_effects` 表和历史数据保留以兼容现有数据库，但运行时不再读取或写入。来源从世界重新发现，已拆掉的信标不会因为旧记录在重启后恢复。无需重新打开原有有效信标的界面。若旧配置把刷新周期设得大于 200 tick，部署前应调整到允许范围，否则启动配置校验会拒绝。

验收以下行为：

1. 镇长/副镇长可打开信标，普通镇员、访客和他镇管理员不能以本镇管理者身份编辑。
2. 使用已存在的有效信标，远离原版范围但仍在本镇领地的访客也能获得效果；领地外不再获得扩散续期。
3. 切换主次效果；同时放置同类不同等级的信标，拆除较强来源后只续期剩余来源的等级，拆除全部来源后停止续期。
4. 分别遮挡光束、破坏金字塔和拆除信标，等待原生更新、插件刷新及原版残留时间后确认旧效果消失；恢复结构后效果恢复。
5. 让来源区块卸载或进入 BORDER 等非运算状态，远处玩家不再获得该来源续期；区块恢复运行后重新验证恢复，插件没有保活来源区块。
6. 重启后原有有效信标自动发现；仅有历史数据库记录而世界中已无信标时不能恢复效果。
7. 离开有效领地、归档、关闭 `territory.beacon.enabled` 并 reload、停用插件后，扩散效果自然到期；玩家药水和原版信标效果不被主动删除。重新开启功能后重新发现来源。

## 诊断与数据恢复

`diagnose [天数]` 同时检查 SQLite 完整性及业务异常、Residence 投影、公共账本和 QuickShop 历史，报告保存在插件目录 `diagnostics`，保留最近 30 份。它不在线备份、不自动修复，历史核对的范围和限制见 [命令手册](../ADMIN_COMMANDS.md)。

启动和手动诊断还会检查有效小镇领地引用的世界 UUID。报告中的 `World UUID` 行列出小镇、数据库世界名、预期 UUID 与实际 UUID；同名世界 UUID 不一致时报告 `UUID_MISMATCH`，世界未加载且找不到同名世界时报告 `WORLD_NOT_LOADED`。世界仅改名而 UUID 不变仍视为有效。此检查不会按名称替换世界或修改数据，也不会阻止恢复入口启动；UUID 异常会让诊断结果显示告警，即使 Residence 几何检查通过。

部署前备份并完成隔离恢复，详见 [SQLite 手册](../operations/SQLITE_AND_BACKUP.md)。故障注入见 [验收矩阵](../operations/ALERTS_AND_FAULT_INJECTION.md)。不要为切换构建而删除、重建或手工改写已有数据库。
