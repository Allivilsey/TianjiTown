# 公共 Buff 部署与验收

适用于 `1.0.0`。当前没有公共资源采购、领取、补发或退款入口；文件名为已有文档路径，不代表资源采购仍可用。数据库 schema `1.1` 的增量迁移新增资金操作表，不包含历史资源订单升级流程。

商店 Buff 仅使用属性修饰符。潜水以 `minecraft:oxygen_bonus` +19 替代水下呼吸，减少水下耗氧，但仍需换气且可能溺水；夜视与防火商品已移除。商店不再施加、追踪或清除药水效果，小镇信标的短时效果独立处理。

## 购买规则

玩家商店由镇长或副镇长操作，使用公共资金购买，选择 1～4 周及商品允许的等级；同类再次购买按新选择覆盖有效项，剩余时间按旧订单实际付款折算退款。速度/生命最高 V、安全落地/矿工最高 III，潜水为 I。商品定义在 `buffs.catalog`，改后重启；价格见 [定价说明](PRICING.md)。

购买与替换退款都在小镇内部账户结算：内部余额变化为旧订单退款减去新订单价格，不调用 Vault，也不改变操作者个人余额。效果应用失败的补偿同样在内部账户完成。

管理员 `/tianjitown buff set <小镇代码> <buffKey> [周数] [等级]` 免费覆盖同类效果，默认 1 周、1 级，允许 1～4 周及商品合法等级（最高 V）。设置不改变公共余额，不受商店和消费开关限制。玩家重购按旧订单实际付款与剩余毫秒占原总毫秒的比例向下取整退款，退款与新扣款在同一事务完成；免费来源退款为 0。确认页显示新价格、预计退款和预计净支出；提交时重新计算并检查旧订单身份。

购买后没有主动退款入口。系统因效果应用失败执行的补偿退款属于故障处理，应核对账户、流水和效果恢复，不等于玩家可申请退货。

## 验收

- 在隔离服确认配置、效果 key 和商品名称校验通过，`status` 为 READY，小镇数据库余额与账本一致，测试小镇账户未锁定。
- 分别测试各属性商品的等级、时长、价格与成员覆盖；玩家普通镇员不能购买，访客不获得成员 Buff。
- 双击确认仅扣款一次；余额不足、消费暂停、商店关闭或账户锁定时不得创建购买记录。
- 验证玩家同类覆盖购买及管理员免费设置，分别核对新等级、价格和到期时间。
- 登录、重生、跨世界后恢复；相同 key 的属性修饰符只有一个。
- 在小镇服内到期、退镇、被移除或归档后清理，生命值不超过恢复后的上限。
- `buffs.shop-enabled: false` 后 `reload` 只停止购买，已有 Buff 继续到期。

## HuskSync 跨服携带

采用“数据库到期时间不变、外服效果允许延后移除”的规则，无需额外子服或 Velocity 插件。

- 正常退出小镇服时不移除玩家的小镇属性修饰符，只取消本服到期任务并释放缓存。
- 玩家停留在小镇服时仍按原时间到期；离线或停留外服时不由本服执行该玩家的到期任务，返回后收尾到期记录。
- 检测到已启用的 HuskSync 3 时，等待 `BukkitSyncCompleteEvent` 后再按数据库校正；没有 HuskSync 时使用普通登录刷新。
- 回服会移除过期及已下架的 `tianjitown:buff_*` 属性修饰符，并将有效的同步属性重新创建为临时修饰符，不延长数据库有效期。
- 未安装 TianjiTown 的子服不会主动处理小镇 Buff 的到期或成员关系变化；接受玩家返回小镇服前的有限超期。
- 插件禁用时仍保留原有在线效果清理流程；本规则针对正常退出和跨服。

在参与同步的子服检查 HuskSync `config.yml`：`synchronization.features.attributes` 应为 `true`，
`synchronization.attributes.synced_attributes`应包含所需属性，
`synchronization.attributes.ignored_modifiers` 不应排除 `tianjitown:buff_*`。
请保留其他插件所需的现有配置。例如速度 Buff 需要明确包含 `minecraft:movement_speed`，
不能假设 HuskSync 默认同步所有属性；潜水 Buff 需要包含 `minecraft:oxygen_bonus`。

跨服验收：

1. 携带未到期属性 Buff 切换到无 TianjiTown 的子服，确认属性效果存在，数据库到期时间未变。
2. 在该子服等待超过到期时间，再返回小镇服；确认 HuskSync 同步后旧修饰符移除，生命值不超过恢复后的上限。
3. 未到期时往返多次，确认数值正确、相同 key 只有一个修饰符、有效期没有重置。
4. 删除或修改 Buff 配置后回服，确认旧属性上的自有修饰符被清理，其他插件的修饰符不受影响。
5. 快速退出重连，确认上一会话的异步回调和到期任务不会影响新会话。
6. 未安装 HuskSync 时验证普通登录恢复、在线到期、退镇清理仍正常。


备份、停服和隔离恢复统一见 [SQLite 手册](../operations/SQLITE_AND_BACKUP.md)。不要把旧 JAR 直接连接到未经验证的当前数据库。
