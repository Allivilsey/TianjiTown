# 玩家使用说明

TianjiTown 不提供玩家命令。所有功能从小镇服务台或小镇手册进入；申请、资料修改、捐款和确认均在 Paper Dialog 内完成。

玩家可完成建镇申请、选址、加入/退出、成员治理、投票、查看完整公共账本、自定义金额捐款、领地扩张和购买公共 Buff。敏感操作会展示对象、费用与后果并要求二次确认。

## 建筑返还

小镇成员在自己小镇有效领地内，以生存模式放置未列入黑名单的普通建筑方块时，有概率返还一个同种方块。命中后操作栏显示“建筑返还 +1”和本周用量。

以下情况不会触发：镇外或他镇领地、创造模式、非成员、自动机械、红石类别和高获取难度黑名单方块、床/门等多方块、容器和特殊方块、带自定义数据的方块、已达到每周 3000 上限、数据库暂时不可用。额度每周一 00:00 刷新。

## 信标增强

位于小镇有效领地和允许世界内的正常工作信标，会以原版效果和等级覆盖整个小镇领地。只有本镇镇长和副镇长可以编辑信标效果；其余信标行为保持原版规则。信标失效、被拆除、离开小镇领地或功能暂停后，效果会自动清理。

建筑返还和领地信标都是小镇公共能力；具体概率、黑名单和允许世界以服务器当前配置为准。
