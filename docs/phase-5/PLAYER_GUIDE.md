# 玩家使用说明

TianjiTown 不提供玩家命令。所有功能从小镇服务台或小镇手册进入；申请资料通过可点击聊天表单填写，规则资料通过书本编辑。

玩家可完成建镇申请、选址、加入/退出、成员治理、投票、查看公共账本、捐款、领地扩张、购买公共 Buff 和领取资源订单。敏感操作会展示对象、费用与后果并要求二次确认。

## 建筑返还

小镇成员在自己小镇有效领地内，以生存模式放置配置白名单中的普通建筑方块时，有概率返还一个同种方块。命中后操作栏显示“建筑返还 +1”和今日用量。

以下情况不会触发：镇外或他镇领地、创造模式、非成员、自动机械、床/门等多方块、容器和特殊方块、带自定义数据的方块、已达到当日上限、数据库暂时不可用。

## 信标增强

位于小镇有效领地和允许世界内的正常工作信标会自动扩大范围，并在服务器安全上限内提高效果等级。信标失效、被拆除、离开小镇领地或功能暂停后，加成会自动清理。玩家不需要领取或执行命令。

建筑返还和信标增强都是领地公共能力；具体概率、每日上限、范围和等级以服务器当前配置为准。
