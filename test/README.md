版本库中的测试资料集中存放于此目录：

- [自动化、命令与运维测试列表](testlist.md)：`AUTO`、`CMD` 与 `OPS` 测试项、执行模板和报告索引；
- [人工测试列表](manualtest.md)：需要真人观察或操作的 `MANUAL` 测试项；
- [测试报告分类](reports/README.md)：按 AUTO/MANUAL 分类存放；当前已有报告全部归入自动测试；
- [TestCommand 自动化接口](test-command.md)：隔离测试服务器使用的自动化接口说明。

各 Maven 模块的自动化测试源码继续保留在模块标准的 `src/test` 目录，确保 Maven 能自动发现并执行。`LocalTestServer`、`MinecraftConsoleClient` 与 `backups` 是本机测试环境及证据目录，不纳入版本控制，报告中的路径仍以项目根目录为基准。

## 测试报告命名规范

- 文档标题使用“`序号 YYYY-MM-DD HH:MM:SS 报告名称`”，时间采用项目时区 `Asia/Shanghai`。
- 文件名使用“`<测试轮次>_YYYY-MM-DD_HH-mm-ss.md`”，例如 `1_2026-08-15_02-23-00.md`。文件名只保留从 1 开始的测试轮次和时间，不加入报告内容描述；Windows 文件名不能包含冒号，因此文件名中的时、分、秒使用连字符，文档标题和索引仍使用标准的 `HH:MM:SS`。
- 时间标记优先使用该轮报告的完成时间；跨日测试使用结束日期和结束时间。
- 新报告必须记录到秒。迁移旧报告时，优先依据测试编号、证据文件写入时间和轮次顺序估算，并在报告开头注明“推测值”；只有无法建立任何可靠顺序时才使用 `00:00:00`，并注明“未知时刻占位”。
- 测试轮次按报告顺序从 `1` 开始递增（如 `1`、`10`），不沿用测试清单的 `15.*` 章节编号；同一测试轮次在同一秒生成多份报告时，在时间后追加两位序号（如 `1_2026-08-15_02-23-00_01.md`）。
