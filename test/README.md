## 测试报告命名规范

- 文档标题使用“`序号 YYYY-MM-DD HH:MM:SS 报告名称`”，时间采用项目时区 `Asia/Shanghai`。
- 文件名使用“`<类型>-R<两位轮次>_YYYY-MM-DD_HH-mm-ss.md`”，例如 `AUTO-R01_2026-08-15_02-23-00.md`。文件名只保留报告类型、轮次和时间，不加入报告内容描述；Windows 文件名不能包含冒号，因此文件名中的时、分、秒使用连字符，文档标题和索引仍使用标准的 `HH:MM:SS`。
- 时间标记优先使用该轮报告的完成时间；跨日测试使用结束日期和结束时间。
- 新报告必须记录到秒。迁移旧报告时，优先依据测试编号、证据文件写入时间和轮次顺序估算，并在报告开头注明“推测值”；只有无法建立任何可靠顺序时才使用 `00:00:00`，并注明“未知时刻占位”。
- 自动测试使用 `AUTO-R01`、`AUTO-R02` 递增命名，手动测试使用 `MANUAL-R01`、`MANUAL-R02` 递增命名；同一类型和轮次在同一秒生成多份报告时，在时间后追加两位序号（如 `AUTO-R01_2026-08-15_02-23-00_01.md`）。
