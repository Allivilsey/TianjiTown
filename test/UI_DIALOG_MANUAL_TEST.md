# Town UI Dialog 手工回归清单

在包含一名管理员、一名镇长、一名普通成员与一名访客的测试服务器上执行。每项记录通过/失败、操作者和异常日志；发现失败时保留复现步骤与服务器日志。

## 导航与会话

- 打开主页，分别进入个人中心、小镇详情、待办、财务和增益商店；验证返回始终回到预期页面。
- 验证关闭按钮与 ESC 均不执行页面操作；关闭后再次点击旧按钮不得产生写入。
- 在分页的首页与末页操作上一页/下一页，确认无越界、无空白页面。
- 打开确认页后分别确认与取消；快速双击确认按钮，验证只执行一次。
- 使用过期、空和畸形 target 的按钮包，验证显示“数据已过期”而不是抛出异常。
- 打开页面后切换到另一页面，再等待原异步读取完成；原请求不得覆盖新页面。
- 玩家退出后等待页面超时或异步回调；不得重新打开页面或写入数据。插件关闭后重复此检查。

## 业务流程

- 服务台：创建、查询、删除、发放手册，及讲台交互、插书、爆炸、活塞和破坏保护。
- 建镇申请：创建、选址、预览、表单草稿保存/放弃、校验失败保留输入、提交、取消及管理员批准/拒绝/要求修改/失败恢复。
- 加入申请：浏览、分页、提交、撤销、管理方批准与拒绝；在详情打开后改变申请状态，再尝试审批。
- 成员与治理：访客增删、角色调整、踢出、镇长转让、规则确认/编辑、创建/投票/撤销投票。
- 财务与商店：税率变更、捐赠输入、账本分页、增益时长选择与购买。
- 领地：批量选择、清空、报价确认、失败退款后重试、预览、跨世界/未加载世界安全传送及传送点设置。
