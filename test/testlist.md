# TianjiTown 核心功能与玩法测试列表

> 适用版本：TianjiTown `1.4.0`，配置 schema `10`，Flyway schema `1.0`，Paper API `26.2`
>
> 更新日期：2026-08-30

本列表只用于确认玩家玩法和管理功能是否能够正常实现，不做发布级的稳定性、安全性与极限验证。

不在本轮范围内：并发与重复请求、数据库或依赖故障注入、强制停服恢复、客户端协议伪造、所有边界值穷举、多客户端兼容、压力测试和长时间运行。需要正式发布验收时，再单独安排这些专项测试。

## 0. 使用说明

- `[ ]`：未测试；`[x]`：通过；`[!]`：失败；`[-]`：本轮不适用。
- 每项按正常操作完成一次即可；只有用例明确要求时，才额外测试权限不足或余额不足。
- 失败时记录实际现象、控制台错误和复现步骤，不要求为通过项保存完整截图或数据库证据。

### 最小测试准备

- 一台安装完整依赖的测试服：Residence、Vault、XConomy、WorldBorder、QuickShop-Hikari、Jobs、GlobalMarketPlus。
- 1 名管理员，1 名建镇申请人，2 名初始成员，另准备普通成员、访客和无镇玩家各 1 名。
- 准备足够的个人余额与小镇公共资金，以及一块可合法建镇、可继续扩张的区域。
