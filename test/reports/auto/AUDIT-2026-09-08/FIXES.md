## 缺陷修复

| 审查项 | 修复结果 | 回归验证 |
| --- | --- | --- |
| 1. 批次重复恢复、重复退款 | pendingExpansions 排除 batch_id 非空的子项；单笔完成和退款在事务内拒绝批次子项 | 批次只出现在批次恢复列表；对子项完成/退款均冲突；批次退款后余额回到 10000 |
| 2. 自动退款结果不确定仍重试 | compensationRequired、空响应和调用异常均停止后续付款；保留操作登记、已有补偿记录和资金锁供人工核实 | 已充值后返回不确定、抛异常、返回 null 均只付款一次；重复 submit 不再付款，不调用补偿完成 |
| 3. QuickShop 税款任务丢失 | 从补贴预留开始排队重试；付款结果随任务保留；明确失败取消补贴并仅入税款；不确定结果保留 RESERVED 和 last_error 并仅入税款 | 预留失败恢复、明确付款失败、成功/不确定/异常/空响应后的账本重试；SQLite 验证税款幂等、无虚构补贴收入、核实证据保留 |
| 4. 未完成扩张充当桥接单元 | 仓储事务拒绝同镇已有 PREPARED/COMPENSATION_REQUIRED 时的新扩张；预览只把 ACTIVE 单元作为现有领地 | 单笔/批次的四种组合均拒绝依赖未完成桥接单元；回滚后领地保持连通 |
| 5. 失效镇长转让占用名额 | 离镇、移除、镇长变化在同一事务取消失效请求；请求清理和查询同时核实双方成员身份及镇长资格 | 主动离镇、管理员移除、管理员转移镇长后均取消旧请求，并允许符合资格的新请求；既有治理投票和转让测试通过 |
| 6. 信标误删外部药水 | 成功添加且当前效果吻合后才记录所有权；监听药水变更释放外部替换的所有权；删除前校验等级、标志与按 tick 推算的精确时长 | 添加被拒、外部替换、签名改变均不删除；成功施加且未改变的自有效果可以清除 |
